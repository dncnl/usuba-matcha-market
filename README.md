# Usuba Matcha Market

Build a demo Shopify store for "Usuba Matcha," a made-up premium Japanese matcha brand.

Products (with Shopify variants, prices in USD, and AI-written descriptions):

- Ceremonial Matcha (30g, 100g)

- Culinary Matcha (100g, 250g)

- Matcha Latte Blend (150g)

- Bamboo Whisk (Chasen)

- Ceramic Matcha Bowl (Chawan) in Stone, Sage, Charcoal

- Matcha Starter Kit (whisk, scoop, bowl, 30g ceremonial)

Collections: Matcha, Teaware, Kits.

Pages: homepage with hero, best sellers and brand story; shop page with collection filters; product pages with variant selector, quantity and add to cart; cart and Shopify checkout; About; How to Brew guide; FAQ; newsletter signup.

Design: calm and premium. Warm off-white background, deep matcha green as the only accent, elegant serif headings with a clean sans-serif body, generous spacing, soft product imagery. Mobile-first, fast, accessible.
